# Контракты взаимодействия (Execool)

Код выполняется в браузере (Pyodide). Сервер нужен для языкового сервера: подсказок, диагностики и перехода к определению. Три интерфейса:

1. Браузер ↔ бэкенд: создание сессии и выдача токенов.
2. Браузер ↔ агент: файлы проекта и WebSocket языкового сервера (напрямую, с токеном от бэкенда).
3. Бэкенд ↔ агент: управление сессиями (внутренний API).

Ошибки везде имеют вид `{"error": "<код>", "message": "<текст>"}`.

---

## 1. Браузер ↔ бэкенд

Базовый путь: `/api/sessions`.

| Метод | Путь | Тело | Ответ |
| :--- | :--- | :--- | :--- |
| **POST** | `/start-lsp` | `{"language_id": "python"}` (необязательно, по умолчанию `python`) | `201`, объект ниже |
| **POST** | `/{id}/lsp-ticket` | — | `200` `{"websocket_url", "ticket", "expires_in_seconds"}`: новый одноразовый билет для переподключения |
| **POST** | `/{id}/files-token` | — | `200` `{"files_token", "files_token_expires_in_seconds"}`: продление токена файлов |
| **DELETE** | `/{id}` | — | `204`, повтор безопасен |

Ответ `POST /start-lsp`:

```json
{
  "session_id": "df6c447e-134b-482e-8876-81d7e587977d",
  "language": "python",
  "root_uri": "file:///workspace",
  "limits": { "max_files": 100, "max_file_bytes": 1048576, "max_total_bytes": 5242880 },
  "agent_url": "http://localhost:6721",
  "files_token": "<токен>",
  "files_token_expires_in_seconds": 900,
  "lsp": {
    "websocket_url": "ws://localhost:6721/sessions/<id>/lsp?ticket=<билет>",
    "ticket": "<билет>",
    "expires_in_seconds": 60
  }
}
```

Ошибки бэкенда:

| Статус | Код | Когда |
| :--- | :--- | :--- |
| 400 | `invalid_id` | Идентификатор сессии не UUID |
| 400, 503 | коды агента | Пробрасываются как есть: `unsupported_language`, `invalid_request`, `capacity` |
| 502 | `agent_error`, `agent_unavailable` | Агент ответил неожиданно или недоступен |

## 2. Браузер ↔ агент

Адрес агента приходит в поле `agent_url`; он может содержать префикс (например, `https://ide.example.com/agent`), все пути ниже дописываются к нему. HTTP-запросы идут с заголовком `Authorization: Bearer <files_token>`. Токен живёт 15 минут, его нужно продлевать через бэкенд.

| Метод | Путь | Тело / параметры | Ответ |
| :--- | :--- | :--- | :--- |
| **GET** | `/ping` | — | `200`, без авторизации |
| **GET** | `/sessions/{id}` | — | `200` `{"id", "language", "files", "lspConnected", "expiresAt", "maxExpiresAt"}`. Заодно продлевает сессию: используется как heartbeat |
| **PUT** | `/sessions/{id}/files` | `{"files": [{"path": "...", "content": "..."}]}` | `204`. Заменяет весь набор файлов; перед записью проверяется целиком |
| **PUT** | `/sessions/{id}/file?path=<путь>` | Тело: текст файла (UTF-8) | `204` |
| **DELETE** | `/sessions/{id}/file?path=<путь>` | — | `204`, повтор безопасен |
| **GET** | `/sessions/{id}/lsp?ticket=<билет>` | — | Переход на WebSocket (см. ниже) |

Правила для файлов:

- Путь: латинские буквы, цифры и символы `. _ - /`, до 120 символов, без `..` и `//`.
- Файлы конфигурации анализатора (`pyproject.toml`, `pyrefly.toml` и подобные) принимаются, но игнорируются: настройки языкового сервера задаёт агент.
- Лимиты по умолчанию: 100 файлов, 1 МиБ на файл, 5 МиБ на сессию (в ответе `start-lsp` в поле `limits`).

### WebSocket языкового сервера

- Билет одноразовый и действует 60 секунд. Для повторного подключения нужен новый (`POST /{id}/lsp-ticket`).
- Каждое текстовое сообщение WebSocket содержит один JSON-RPC без заголовков `Content-Length`.
- На сессию приходится одно подключение: новое вытесняет прежнее.
- Адреса документов: `file:///workspace/<путь>`. Заглушки стандартной библиотеки отображаются как `file:///typeshed/...` и в браузере не открываются.
- Об изменениях файлов на диске агента клиент сообщает уведомлением `workspace/didChangeWatchedFiles` после успешной записи.

Коды закрытия соединения:

| Код | Значение | Что делать |
| :--- | :--- | :--- |
| 4001 | Сессия удалена или истекла | Создать новую сессию |
| 4002 | Языковой сервер не запустился | Показать ошибку |
| 4003 | Закрыто по простою | Получить новый билет и переподключиться |
| 4010 | Вытеснено новым подключением | Не переподключаться |

### Ошибки агента

| Статус | Код | Когда |
| :--- | :--- | :--- |
| 400 | `invalid_path`, `invalid_request` | Путь или тело запроса недопустимы |
| 401 | `unauthorized` | Токен неверный, просрочен или выдан для другой сессии или агента |
| 404 | `session_not_found` | Сессии нет или она истекла |
| 413 | `file_too_large`, `too_many_files`, `session_too_large`, `payload_too_large` | Превышены лимиты |
| 503 | `capacity` | Агент занят: нет места под сессию или под процесс языкового сервера |

## 3. Бэкенд ↔ агент (внутренний API)

Префикс `/internal`, заголовок `Authorization: Bearer <AGENT_API_KEY>`. Если задан `AGENT_INTERNAL_ALLOWED`, запросы принимаются только с перечисленных адресов (остальные получают `401`).

| Метод | Путь | Тело | Ответ |
| :--- | :--- | :--- | :--- |
| **GET** | `/internal/status` | — | `200` `{"agentId", "languages", "sessions", "maxSessions", "lspActive", "lspSlotsFree"}` |
| **POST** | `/internal/sessions` | `{"id": "<uuid>", "language": "python"}` | `201` `{"id", "language", "rootUri", "limits": {"maxFiles", "maxFileBytes", "maxTotalBytes"}}`. Повтор с тем же `id` возвращает ту же сессию |
| **DELETE** | `/internal/sessions/{id}` | — | `204`, повтор безопасен |

`rootUri` всегда `file:///workspace`. Настоящий путь рабочей папки на сервере браузеру не показывается.

---

## Токены

Бэкенд выпускает, агент проверяет. Формат:

```
base64url(JSON) + "." + base64url(HMAC-SHA256(секрет, base64url(JSON)))
```

Секрет общий (`AGENT_TOKEN_SECRET`), без заголовка, подпись только над payload. Поля JSON:

| Поле | Значение |
| :--- | :--- |
| `sid` | Идентификатор сессии |
| `scope` | `files` (HTTP-запросы к файлам) или `lsp` (билет WebSocket) |
| `exp` | Время окончания, секунды Unix |
| `jti` | Уникальный идентификатор |
| `aud` | Идентификатор агента (`AGENT_ID`) |

Токен действует только для своей сессии, своего агента и своего `scope`. Билет `lsp` принимается один раз.
